# My Personal Website

A personal website showcasing my projects, skills, interests, and online profiles.

## 🌐 Live Website

https://lpcomix123.github.io/my-personal-site/

## 📖 About

I made this website to show off my projects, skills, interests, and achievements. I also added my own colours and style to make it unique.

## ✨ Features

- a fully working navbar with a hamburger menu on mobile
- a fully working custom 404 page
- about, current/featured projects, skills/certifications, interests and links/contacts sections
- an entire dedicated more-projects page
- and links at the bottom, all with there respective images and hover effect.

## 🛠️ Built With

- **HTML** — to make the actual website
- **CSS** — to make the website look good
- **Images** — to add my certifications and add images to the links at the bottom
